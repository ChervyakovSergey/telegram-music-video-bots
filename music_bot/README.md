# 🎵 Telegram-бот для поиска музыки (Audius + SoundCloud)

Личный бот: пишешь название трека — он ищет сразу на **Audius** и **SoundCloud**
и присылает трек в **лучшем доступном качестве**, который Telegram проигрывает
прямо в чате.

## Качество звука
| Источник | Качество | Значок в списке |
|---|---|---|
| **Audius** | MP3 **320 kbps** | 💎 |
| **SoundCloud** | до **AAC 160 kbps** (раньше бот брал mp3 128) | без значка |

- Файлы отправляются **как есть, без перекодирования** — любое пережатие только
  ухудшило бы звук.
- Под каждым присланным треком подписано его **реальное качество**, прочитанное из
  самого файла (например, «🎧 MP3 320 kbps · Audius»).
- Честно: цифра — это битрейт файла. Если исполнитель изначально залил трек
  в плохом качестве, 320 kbps звук не улучшат.
- Lossless (FLAC/WAV) бесплатно и открыто почти не встречается, а в платных
  стримингах поток зашифрован — такое бот не качает.

## Порядок в выдаче
1. 💎 Треки Audius, залитые **самим исполнителем** из запроса (оригинал + 320 kbps).
2. Первые результаты SoundCloud.
3. 💎 Остальное с Audius (каверы, ремиксы, флипы).
4. Остальной SoundCloud.

С Audius показываются только треки, где в названии/исполнителе есть все слова
запроса, и только те, что влезают в лимит Telegram (в 320 kbps это ≈21 минута).

## 🎭 Музыка под настроение — `/mood`
Кнопки: 😢 Грустное, 📚 Спокойное, 😎 Чилл, 🥰 Романтичное, 🎉 Весёлое,
🏃 Для спорта, 😤 Дерзкое, 🌙 Задумчивое. Бот берёт 50 популярных треков Audius
с таким настроением (все в 320 kbps) и перемешивает их — каждое нажатие даёт новую
подборку. Кнопки настроений остаются в чате, можно сразу выбрать другое.

## 📶 Прогресс скачивания
Пока трек качается, статус показывает полоску: `▰▰▰▰▰▰▱▱▱▱ 61%`, потом
«📤 Отправляю в Telegram…» — на этом этапе время зависит от скорости твоего
интернета. Если трек уже предзагружен, статуса нет — сразу приходит аудио.

## Что умеет ещё
- Результаты **постранично** (кнопка «Ещё ▶️»).
- **Обложка** в плеере Telegram.
- **Предзагрузка**: первые 3 трека списка качаются заранее, пока ты выбираешь.
- Статус «⬇️ Качаю…», команды `/start` и `/help`.
- Кэш — повторная отправка трека мгновенная (`cache_v2.json`; старый `cache.json`
  с треками в mp3 128 больше не используется, его можно удалить).
- Работает **только для тебя** (фильтр по Telegram ID).

## Как устроено
- Бот (`bot.py`) — на `aiogram`, запускается на venv проекта.
- **SoundCloud** — библиотека `yt-dlp` прямо в процессе. Выбирается поток с самым
  высоким битрейтом; 30-сек превью платных треков отсекаются.
- **Audius** — открытое API (`api.audius.co`), аккаунт и ключ не нужны.
- Теги и обложки пишет `mutagen`; `ffmpeg` нужен для обложек у SoundCloud.

## Особенности
- Часть мейнстрим-треков на SoundCloud защищена (DRM) или доступна только как
  30-сек превью (видно как `0:30`) — бот скажет «🔒 выбери другой».
- Каталог Audius — в основном электроника, хип-хоп, инди. Мейнстрима там мало.

## Установка (по шагам)

### 1. Получи токен бота
1. Напиши в Telegram боту **@BotFather** → команда `/newbot`.
2. Скопируй выданный **токен** (вид: `1234567890:AA....`).

### 2. Настрой `.env`
```bash
cd music_bot
cp .env.example .env      # затем впиши BOT_TOKEN (и позже OWNER_IDS)
```
Свой Telegram ID узнавать отдельно не нужно: запусти бота, нажми **Start** —
он пришлёт строку «Твой Telegram ID: …». Впиши это число в `OWNER_IDS` и
перезапусти, чтобы бот отвечал только тебе.

### 3. Зависимости (уже установлены)
- Python-пакеты: `../venv/bin/pip install -r requirements.txt`
- `ffmpeg`: `brew install ffmpeg`

### 4. Запусти
```bash
../venv/bin/python bot.py
```
Открой бота в Telegram, нажми **Start**, пришли название песни → выбери трек.
