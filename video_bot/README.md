# 📥 Telegram-бот для скачивания видео

Личный бот: кидаешь ссылку на видео из **YouTube / TikTok / Instagram** —
он скачивает и присылает видео в чат.

## Что умеет
- Качает по ссылке, видео играет прямо в Telegram.
- Качество подбирает сам: до 720p; если файл больше лимита Telegram (~50 МБ) —
  автоматически пробует 480p, потом 360p.
- Работает **только для тебя** (фильтр по Telegram ID).
- Понятные сообщения об ошибках (приватное видео, нужен логин и т.п.).

## Как устроено
- Бот на `aiogram`, работает на venv проекта (`../venv`).
- Скачивает **standalone-бинарник yt-dlp** — общий с музыкальным ботом
  (`../music_bot/yt-dlp`). Обновлять: `../music_bot/yt-dlp -U`.
- Для YouTube нужны **cookies браузера** и **deno** (уже настроены для
  музыкального бота). Для Instagram — те же cookies (должен быть логин в Инсту
  в этом браузере). TikTok обычно работает без всего.

## Установка (по шагам)

### 1. Создай ВТОРОГО бота
Напиши **@BotFather** → `/newbot` → придумай имя (например, video_bro) →
скопируй **токен**.

### 2. Настрой `.env`
```bash
cd video_bot
cp .env.example .env    # впиши BOT_TOKEN; OWNER_IDS — после первого /start
```

### 3. Запусти
```bash
../venv/bin/python bot.py
```
Открой нового бота в Telegram, нажми **Start**, пришли ссылку на видео.
После первого ответа впиши свой ID в `OWNER_IDS` и перезапусти.

## Частые вопросы
- **YouTube пишет «подтверди, что не бот»** — проверь `COOKIES_FROM_BROWSER=chrome`
  в `.env` и что в Chrome ты залогинен в YouTube.
- **Instagram не качает** — в том же браузере должен быть выполнен вход в Instagram;
  приватные посты качаются только если твой аккаунт имеет к ним доступ.
- **«Видео слишком большое»** — ролик не влез в 50 МБ даже в 360p (обычно это
  длинные видео). Такое ограничение у Telegram для ботов.
- **Что-то перестало качаться** — обнови yt-dlp: `../music_bot/yt-dlp -U`
  и перезапусти бота.

## Важно
Только для **личного использования**. Соблюдай авторские права и правила
